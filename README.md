# Weather Data Analysis & Temperature Prediction 🌦️

## 📌 Project Overview
This project analyzes historical weather data and predicts future average temperature trends using Machine Learning.

A Linear Regression model is trained on cleaned real-world weather data to forecast temperature values.

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

---

## 📂 Dataset
- Historical daily weather data (`weather.csv`)
- Features used:
  - Year
  - Month
  - Day
  - AvgTemperature

Temperature values are originally in **Fahrenheit**.

---

## 📊 Steps Performed
1. Loaded real-world weather dataset
2. Cleaned missing and invalid values
3. Filtered data by city for better analysis
4. Visualized temperature trends over time
5. Trained a Linear Regression model
6. Predicted future average temperature

---

## 🔮 Sample Output
- Temperature trend visualization  
- Future temperature prediction after 30 days

---

## ▶️ How to Run
1. Open the notebook `weather_prediction.ipynb` in Google Colab
2. Upload `weather.csv`
3. Run all cells
